Repozytorium zawiera finalny **LaTeX + PDF**, wyniki z 770 ASV/34 próbek (*Moving Pictures*), nową metodę certyfikatów budżetowych i hierarchicznych, syntetyczny benchmark, niezależną walidację rankingów na 41 328 ASV (*gut-to-soil*), skrypty i rysunki. **Pliki .md są dozwolone.**
