# Rights and public-release checklist

- [ ] Authors approve release of the code and generated data/figures.
- [ ] Redistribution rights and required citations are confirmed for the included QIIME 2 table, metadata visualization, SILVA 138 and Greengenes2 2024.09 annotations.
- [ ] Public source of the independent GTDB/SILVA QZV is still accessible without requiring reviewer identity; download/checksum was tested.
- [ ] Code license and third-party attributions are approved. No unapproved MIT/Apache/CC license is assigned by this candidate.
- [ ] Data statements in `main.tex`, `README.md` and CMT agree exactly with what is publicly accessible.
- [ ] Repository is public and works from a new, unsigned browser; GitHub Actions verification passes.
- [ ] A GitHub release is tagged only after the artifact passes these checks.
- [ ] For an ICDE EAB submission, every reported result can be reconstructed from supplied artifacts or legal, accessible input sources. Supplementary material is mandatory without exceptions in EAB.

This package is a **publication candidate**, not evidence that these rights have already been cleared or that a GitHub repository has already been created.
